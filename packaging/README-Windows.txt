Quality-of-Life Tracker (Windows)
=================================

1. First unzip: right-click the ZIP, choose "Extract All...", and open the
   extracted folder. (Running PetQoLTracker.exe from inside the ZIP won't work.)

2. Double-click PetQoLTracker.exe.
   A black window opens and shows an address like http://127.0.0.1:5000/.
   Your web browser should open on it by itself. If it doesn't, double-click
   "Open the app" in the same folder, or type that address into your browser.
   Leave the black window open while you use the app; closing it stops the app.
   To open the app another day, double-click PetQoLTracker.exe again.

3. If Windows shows a blue "Windows protected your PC" box, click
   "More info" and then "Run anyway". That box appears because the app
   isn't from the Microsoft Store, not because anything is wrong with it.

Your entries are saved in the "data" folder next to PetQoLTracker.exe.
Keep this whole folder together. Back up from the More page now and then.

To try it with sample pets first, the app has a demo: open a Command Prompt
in this folder and run:  PetQoLTracker.exe --seed-demo

Updating to a newer version: download the ZIP again, extract it to a new
folder, then move your "data" folder from the old folder into the new one.
That folder holds all your entries and photos.
